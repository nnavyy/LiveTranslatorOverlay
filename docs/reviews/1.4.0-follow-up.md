# Review follow-up for v1.4.0

The original review remains a historical snapshot of v1.3.3. Version 1.4.0 addresses the following items; it does not claim the whole review is resolved.

| Finding | Status in this release |
|---|---|
| F01 | Fixed near-match cache reuse. Normal and streamed changed-number regression checks pass. |
| F02 | Removed ordinary-word/short-length rejection; explicit noise tags and repetition checks remain. Real speech quality/native review remain to be measured. |
| F03 | Fixed pause-driven emission of short voiced playback; overlap-only data is not emitted repeatedly. Stop still discards pending capture. |
| F04 | Removed all version-based report resolution. Only explicit, validated status entries change a report. |
| F05 | Partial: no global process termination, expected ZIP/executable checks, graceful process exit, failure exit code handling, retained staging. Full rollback, authenticated manifests, and installation failure testing remain. |
| F06 | Removed idle/exit update restarts. Restart-to-install is an explicit action and blocked during live capture. |
| F07 | Removed raw transcript debug writes and documented the MyMemory fallback recipient. Existing logs and other optional diagnostics still need user-controlled retention. |
| F08 | Open: awaited bounded audio processing, session isolation, serialized sends, and comprehensive reconnection handling. |
| F09 | Partial: Auto explicitly requests Nova-2 English/Spanish multilingual mode; source changes advise restarting audio. Full capability filtering/reconnection remains. |
| F10 | Fixed unchanged-success fallback behavior and application-error response validation. |
| F11 | Request identity includes languages, engine, script style, and text; OCR restart invalidates identity. End-to-end screen/device checks remain. |
| F12 | Partial: UI language restores by tag and capture preference is retained on save. Settings path, encryption, atomic saving, and visible save errors remain. |
| F13 | Partial: current version in payload, explicit delivery success, and visible refresh failure. Draft/delivery state separation and mailto tracking remain. |
| F14 | Partial: OCR error strings are displayed directly; new notes window follows capture exclusion. Existing summary windows and full mixed-DPI/capture coverage remain. |

Product additions: version-specific release notices in four interface languages, a Spanish interface draft, nine language choices, and regression checks in CI. New selector entries do not assert that Windows OCR packs are installed or that all models have equal speech accuracy.
